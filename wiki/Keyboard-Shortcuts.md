# Keyboard shortcuts

Every command below can be rebound in **Settings → Keyboard**. The defaults are listed here.

Fixed keys, which can't be rebound: the arrow keys, Enter, Escape, Home and End, Page Up and Page Down, and type-to-find. Alt+0 to Alt+7 set colour tags.

## Panes and tabs

| Action | Keys |
|---|---|
| Toggle dual pane | Ctrl+D |
| Switch to the other pane | Tab |
| Move to other pane / copy to other pane | F6 / Shift+F6 |
| Copy to… / Move to… | F7 / Shift+F7 |
| Compare with other pane | Ctrl+Alt+M |
| New tab / close tab | Ctrl+T / Ctrl+W |
| Reopen closed tab | Ctrl+Shift+T |
| Next tab / previous tab | Ctrl+Tab / Ctrl+Shift+Tab |
| New tab from clipboard path | Ctrl+Shift+V |
| New window | Ctrl+N |
| Rename tab | (no default) |
| Close tabs unused for an hour | (no default) |

## Navigation

| Action | Keys |
|---|---|
| Back / forward | Alt+Left / Alt+Right |
| Up one level | Alt+Up, Backspace |
| Type a path | Ctrl+L |
| Refresh | F5, Ctrl+R |
| Go to favourite 1 to 9 | Ctrl+Alt+1 to Ctrl+Alt+9 |
| Add folder to Favorites | Ctrl+B |

## Views and panels

| Action | Keys |
|---|---|
| Columns / list / thumbnails view | Ctrl+1 / Ctrl+2 / Ctrl+3 |
| Show or hide hidden files | Ctrl+H |
| Preview panel on or off | Ctrl+P |
| Show or hide the terminal panel | Ctrl+` |
| Settings | Ctrl+, |

## Selection and files

| Action | Keys |
|---|---|
| Select all | Ctrl+A |
| Select by pattern / deselect by pattern | + (or Shift++) / - |
| Cut / copy / paste | Ctrl+X / Ctrl+C / Ctrl+V |
| Copy path | Ctrl+Shift+C |
| Duplicate | Ctrl+Shift+D |
| Rename, or batch rename several items | F2 |
| Batch rename | Ctrl+F2 |
| New folder / new text file | Ctrl+Shift+N / Ctrl+Alt+N |
| Move to Trash | Delete |
| Delete permanently | Shift+Delete |
| Properties | Alt+Enter |
| Undo | Ctrl+Z |
| Add to Drop List | Alt+D |
| New folder with selection, compress, extract here, open with, symbolic link | (no default) |

## Search and filtering

| Action | Keys |
|---|---|
| Search in this folder | Ctrl+Shift+F |
| Filter this folder | Ctrl+F |

## Viewing and comparing

| Action | Keys |
|---|---|
| Quick Look | Space |
| View file | F3, Ctrl+Q |
| Edit file | F4 |
| Compare two files | Ctrl+Alt+D |
| Connect to server | (no default) |
